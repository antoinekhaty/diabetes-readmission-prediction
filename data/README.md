# Public dataset and privacy

This repository contains **no individual-level hospital records**.

For a local run, obtain the public [Diabetes 130-US Hospitals dataset](https://archive.ics.uci.edu/dataset/296/diabetes+130+us+hospitals+for+years+1999+2008) from the UCI Machine Learning Repository. Place the CSV outside the repository, and pass its path with the --csv option.

Do not commit private patient information, CSV data extracts, or other individual-level research records. Common data formats are excluded in .gitignore.
